軟口蓋鼻音 /ŋ/ は語頭・発話頭に立つことがなく、さらには閉音節の直後に来ることもありません。その由来や音声的実現にかかわらず、/ŋ/ は常にコーダしか占めないとして分析し、そのように表記されます。なお、コーダ位置で軟口蓋鼻音を表すために用いられる文字ㅇは、オンセット位置で用いられるとゼロ子音を表します。

### ㅔとㅐの発音について

規範としてはこれらはそれぞれ半狭・半広で発音されるということになってはいますが、朝鮮中央テレビのアナウンサーも正書法上のこれらの区別と音声での反映との間に一貫性がないという研究もあるため、対立が残存しているとは言い難いとhsjoihsは判断します。

## 半母音+母音（として発音されうる母音字）

### /j/ を伴うもの

先ほど見せた七母音を表す八種の母音字のうち、短い棒を持つㅏㅓㅗㅜㅐㅔは、短い棒の本数を倍増させることにより、「/j/ + 母音」を表します。

ㅏ→ㅑ /ja/, ㅓ→ㅕ /jŏ/, ㅗ→ㅛ /jo/, ㅜ→ㅠ /ju/, ㅐ→ㅒ /jae/, ㅔ→ㅖ /je/


### ㅖ
계, 례, 혜はそれぞれ[게], [레], [헤]、それ以外は基本的に[ㅖ]で発音されます。

### 円唇性を伴うもの

後舌かつ円唇の単母音を表すㅗやㅜの字と、前舌または中舌の単母音を表すㅣㅔㅐㅓㅏの字を組み合わせることにより、以下の複合字母が構築されます。

| | ㅜ | ㅗ |
|:--:|:--:|:--:|
| ㅣ | ㅟ |ㅚ |
| ㅔ | ㅞ |  |
| ㅐ | | ㅙ |
| ㅓ | ㅝ | | 
| ㅏ | |  ㅘ |

これらは発音に円唇性を伴います。

ㅞㅙㅝㅘは（規範も実態も）対応する前舌または中舌母音の前に /w/ を発音するという字母です。
ㅟ は単母音 /y/ で発音される例もたまに耳にしますが、多くの場合実態は /wi ~ ɥi/ です。
ㅚ は単母音 /ø/ で発音される場合もㅞやㅙのように発音されることも共に珍しくないという印象です。

### ㅢ

規範では「二重母音で発音することを原則とする」と書きつつも、附則 (불임) にて

- 子音が結合したときや、単語の途中および末尾にある ㅢ は [ㅣ] で発音することを許容する
   - 例: 희망[희망/히망] 띄우다[띠우다], 씌우다[씨우다]
   - 결의문[겨릐문/겨리문], 정의 [정이], 의의 [의이], 회의[회의/회이]
- 属格の토として使われる場合一部 [ㅔ]と同様に発音することを許容する
   - 例: 혁명의 북소리 [형명에 북쏘리]
   - 우리의 집은 당의 품[우리에 지븐 당에 품] 

と記載されている。<small>（ㅢ と ㅣ の両方を併記する場合と、ㅣ しか提示していない場合があるが、その差は少なくともhsjoihsには謎。）</small>

実用上は、

- 語頭に来ているときには [ɰi]
- 属格助詞は [e]
- それ以外なら [i]

とすればよかろう。

:<: b ねぎ補足
時折律儀に[ㅢ]で発音する人もいるが、圧倒的少数なので見かけた際はレアケースだなぁくらいに思っておくと良い。

## 文化語の音節

文化語の音節は (C)(G)V(C)、つまり

- 前述の表から /ŋ/ を除いた頭子音（ゼロでありうる）
- 母音もしくは「半母音 + 母音」
- 以下に述べる 7 種類のコーダ、もしくはゼロ

によって構成される。

### 7 種類のコーダ

コーダ位置では、摩擦音・破擦音が表れない。
また、口音に存在した平音・激音・濃音の対立が潰れる。この教材では、慣習に合わせて平音の字母を用いて表記するが、archiphoneme であることを明記すべく ⫽ㅂ⫽ などと表記することとする。

# 文化語における曲用と活用

次の章で「綴りと発音の不一致」について説明するが、
その前に「<b>どのような言語現象を表そうとして</b>そのような仕組みが作られているのか」について知っておく必要がある。

というのも、朝鮮語における綴りと発音の不一致の中には

- 音素配列論的制約による自動的なもの
- ある程度「語幹の文字」と「語尾の文字」を分けて表記しつつ、中程度に複雑な体言の曲用と動詞の活用を表現できるようにするための工夫
- 暗記する必要がある語彙的現象

の 3 種類が混ぜこぜになっているからである。

よって、ここではまず表音的に文化語における曲用と活用について解説する。

## 用言

hsjoihs は、朝鮮語の用言を【母音・リウル語幹】【激音化語幹】【濃音化語幹】の 3 種類に分類すべきであると考える。

### 母音・リウル語幹

語幹が母音またはㄹで終わる語幹であり、直後の接辞と結合する際に [ㅡ] を用いることがなく、直後の接辞が平音であることが許される。

### 激音化語幹

[ㅡ] を用いずに語幹が直後の接辞と結合する際、直後の接辞に平音を許さず、代わりに<b><u>激音</u></b>が登場する。

### 濃音化語幹

[ㅡ] を用いずに語幹が直後の接辞と結合する際、直後の接辞に平音を許さず、代わりに<b><u>濃音</u></b>が登場する。

なお、濃音化語幹の用言の一部には、語幹として √(C)(G)V<b>C</b> と √(C)(G)V<b>CC</b> の両形を有するものがある。そのような語の場合、直後に母音が現れるときは長いほうの語幹を、さもなくば短いほうの語幹を用いる。

## 用言の活用

まず、[ㅡ] を用いうる接辞について述べる。

- 母音・リウル語幹のときには [ㅡ] を用いない
- 激音化語幹・濃音化語幹の場合は [ㅡ] を用いる
   - これは「直後に母音が現れるとき」に該当するため、語幹が 2 種類ある濃音化語幹用言は長い方の語幹を用いる。

:<: b <b style="color:blue; text-decoration:none;">青文字</b>についての補足

「綴りと発音の不一致」とはあまり関係しないので補足送りとしているが、「〜して」を表す[-어]/[-여]/[-아]は以下のようにして決まる。

- 하다 → 여
- かつて /j/ 終わりの語幹であった、構成要素にㅣを含む母音字で終わる母音語幹 → 여
- ㅗ, ㅏ, ㅑの影響力が強い → 아<ul><li>具体的な条件：「最終音節の母音が ㅗ, ㅏ, ㅑ」または「語幹が複音節かつ ㅡ 終わりであって、その1つ前の音節の母音が ㅗ, ㅏ, ㅑ」</li></ul>

また、これらの語尾は、

- 直前にコーダがあれば、それをオンセットとする
- 直前の母音と適宜縮合する

といった現象を起こす。これらの現象に若干注意を惹いてもらえるよう、ひっくるめてここでは青文字で示した。

## 体言

体言は、その語幹に応じて分類される。無数にある open class と少数しかない closed class に分けられ、借用語・新語は全て open class のほうで作られる。体言の曲用は、単立形と位格形を覚えれば残りの全てがそこから導出できるため、以下 〈[単立形] - [位格形]〉として表音的に表記する。

### 無数にある open class

母音・鼻音・流音で終わる語幹を持つ名詞は無数にある。

- 母音幹名詞： 〈[자유] - [자유에]〉「自由」など多数
- -m 幹名詞： 〈[신심] - [신시메]〉「信心」など多数
- -n 幹名詞： 〈[조선] - [조서네]〉「朝鮮」など多数
- -ŋ 幹名詞： 〈[열쩡] - [열쩡에]〉「熱情」など多数<ul><li>文字の上ではオンセットに来る /ŋ/ を表記できないのでコーダとして綴るが、歌唱上での発声タイミングなどを鑑みるに、他と同様に音声上はオンセットに来ていると見なすべきであると hsjoihs は考える。</li></ul>
- -r 幹名詞： 〈[기술] - [기수레]〉「技術」など多数

平音で終わる語幹のうち、以下の 3 種が open class である。

- -p 幹名詞： 〈[위업] - [위어베]〉「偉業」など多数
- -k 幹名詞： 〈[조국] - [조구게]〉「祖国」など多数
- -s 幹名詞： 〈[<b style="color:red">곧</b>] - [고세]〉「ところ」など比較的多数

中期朝鮮語においては、몯〮 (Yale: mwót)「釘」と 못〮 (Yale: mwós)「池」といったふうに、-t 幹名詞と -s 幹名詞は対立していたが、後に中和した。この際、現代語の音声としては両方の単立形が ⫽ㄷ⫽ コーダとなったが、曲用のパラダイムとしては「圧倒的多数であった -s 幹へと、元来 ㄷ で終わっていた名詞が全て吸収される」という形となったため、現代の文化語においては -t 幹名詞のパラダイムは存在しない。

:<: b -s 幹名詞は文化語において本当に open class か？

南において -s 幹名詞が open class であることは疑いようがない。借用語 <span class="south">〈[인터넫] - [인터네세]〉「インターネット」</span>や <span class="south">〈[초콜릳] - [초콜리세]〉「チョコレート」などが存在するからである。

しかし、文化語ではこれらの語は [트] などで終わる母音語幹として借用されているため、-s 幹名詞が文化語においても本当に open class であるとは直ちには言い難い。ただ、文字名の挙動（後述）から見るに、まだ open class であるといっても差し支えないであろう。

:>:

### 少数しかない closed class

平音を語幹末に持つ名詞としては、他にㅈで終わるものがある。

- -j 幹名詞：〈[낟] - [나제]〉「昼」など

位格形で激音が出る名詞は以下の通り。なお、中期朝鮮語において、[h で終わる名詞は場所を表すものが多い](https://en.wiktionary.org/wiki/Appendix:Middle_Korean_h-final_nouns)ことが知られている。

- -ch 幹名詞：〈[꼳] - [꼬체]〉「花」など
- -kh 幹名詞：〈[부억] - [부어케]〉「台所」および 〈[-녁] - [-녀케]〉「〜側」を含む語のみ
- -th 幹名詞：〈[받] - [바테]〉「畑」や〈[끋] - [끄테]〉「最後」など
- -ph 幹名詞：〈[압] - [아페]〉「前」など

また、中期朝鮮語において語幹末に子音クラスタを持っていた少数の名詞が作るクラスもいくつかある。

- -kk 幹名詞：〈[박] - [바께]〉「外」およびその派生語のみ
   - 中期朝鮮語 -sk 由来。当時は 〈밧 (Yale: pàs) -  밧긔〮 (Yale: pàskúy)〉というふうに交替した
- -kss 幹名詞：〈[목] - [목쎄]〉「分け前」・〈[넉] - [넉쎄]〉「魂」・〈[삭] - [삭쎄]〉「賃金」の 3 語のみ
   - 中期朝鮮語 -ks 由来。当時は常に 넋 (Yale: nèks) のように子音クラスタが安定していた 
- -pss 幹名詞：〈[갑] - [갑쎄]〉「価値」およびその派生語のみ
   - 中期朝鮮語 -ps 由来。当時は常に 값〮 (Yale: káps) のように子音クラスタが安定していたが、16 世紀になると s が落ちて表記される例が多くなっていくとのことである（福井玲「韓国語音韻史の探究」p.71）
- -rss 幹名詞：〈[골] - [골쎄]〉「一途」とその複合語、〈[돌] - [돌쎄]〉「～周年」、〈[올] - [올쎄]〉「代償」のみ。
   - 中期朝鮮語 -rs 由来。当時の語形は 돐〮 (Yale: twóls) であったと推察されるが、実際に単独形で現れた用例は見られないとのことである（福井玲「韓国語音韻史の探究」p.55）
- -rk 幹名詞：〈[닥] - [달게]〉「鶏」や 〈[흑] - [흘게]〉「土」など。
   - 中期朝鮮語 -rk 由来。当時は常に <span class="south">ᄃᆞᆰ</span> (Yale: tòlk) のように子音クラスタが安定していた 

:<: b 補足： -rss 幹名詞の南北差

文化語発音法第9項の1には「一途」の主格形の発音が [골시] であると例示されている。

南の規範ではこの語の主格形は<span class="south">[골씨]</span>であると明記されているため、一見これは南北差であるように見える。

しかし、2014 年版 문화어발음사전（文化語発音辞典）を引くと、この語の主格形は [골씨] である（すなわち、曲用パラダイムは〈[골] - [골쎄]〉である）との記載がある。よって、hsjoihsは[골시]を文化語発音法のミスであると見なし、これらを -rss 幹名詞であると分析する。

本物の南北差としては、〈[돌] - [돌쎄]〉を挙げるべきであろう。南もかつてはこの語形を用いていたが、1988 年の標準語改訂で、この語は南では<span class="south">〈[돌] - [도레]〉</span>と曲用する -r 幹名詞であると改訂された。

:>:

:<: b 補足： -rp 幹名詞

<div class="south">

南の規範としては、この他に中期朝鮮語 여듧〮 (Yale: yètúlp) に由来する -rp 幹名詞〈[여덜] - [여덜베]〉「八」があるとされるが、現代語でのこの語の実態は南北ともに -r 幹名詞〈[여덜] - [여더레]〉であるため、北の規範では「八」は -r 幹名詞として曲用すると見なす。ただし綴りは変えがたかったため、南北共に正書法上はこの語がまるで -rp 幹を持っているかのように綴る。

</div>

:>:

最後に、文法規則上は open class であるとされているが実態はかなり限られる語幹末について説明する。

- -r-m 幹名詞：〈[암] - [알메]〉「知識」・〈[삼] - [살메]〉「人生」など
   - 現代語では r で終わる用言語幹に名詞化接辞 -m が付随すると必ずこれになる……<b>という建前になっている</b>。しかし、<small>（南の文献の和訳を引くことになってしまうが）</small>金鍾徳「韓国語を教えるための韓国語の発音システム」p.164 に「このように形成された語形は名詞でなく名詞形で、その使用頻度も実情は高くないため、正確な発音を見つけ出すのが難しい。」とあり、実態としてはあらゆる r 終わりの用言語幹から -r-m 幹名詞を作り出せるわけではないようである。
   - 中期朝鮮語には存在しない形。当時は r 語幹の用言に名詞化接辞 -m を付ける際には間に母音を挟む必要があった。
      - 母音を挟んだ形のまま -m 幹名詞として現代語に残存している語としては、〈[사람] - [사라메]〉「人」や 〈[어름] - [어르메]〉「氷」などを挙げることができる。
      - [南の文献である<span class="south">우리말샘</span>](https://opendict.korean.go.kr/dictionary/view?sense_no=220727&viewType=confirm)によれば15世紀から18世紀頃までは動詞語幹 알- に名詞化接辞 -m を付けてできた語の語形は -m 幹名詞 [아롬] であり、現代語のような -r-m 幹名詞にとって代わられるのはそれ以降の時代であるとのこと。
