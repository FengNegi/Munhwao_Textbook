# おわりに ～規範と文化語の現在～
ここまで《朝鮮語規範集》及び《朝鮮語大辞典》をもとに文化語の規範を中心に学習を進めてきた。
しかしながら、ここで疑問に思うだろう、
:<: box
｢規範｣とそれに沿った｢作品類｣だけを俯瞰して、一体何になるのだろう？
:>:
と。
それを理解いただくためにも、次の文章を読んでみよう。

:<: box
　北朝鮮における書体への愛着は特異なものであり、特に白頭山3大将軍の金日成筆跡は「太陽書体」、金正日筆跡は「白頭山書体」、金正淑筆跡は「海抜書体」と名付けられ「民族の最高の遺産」として神聖視されている。これに関連して、書体研究討論会の開催をはじめ、学生への模写教育活動までも行っている。北朝鮮では、指導者がこの見本の書体を示すだけでなく、自国産製品のロゴやパッケージデザインに使用される書体の決定にも関与しており、名製品や名商品を開発するための重要な役割までも果たしている。
:>:

[《総説》北朝鮮における言語政策と活字文化の概括 劉賢国（筑波技術大学・教授）](https://www.ritsumei.ac.jp/research/aji/asia_map_vol03/north_korea/country01/)より

さて上掲の文章だが、1箇所｢誤訳である｣と推察されるものが1つある。それを探してみよう。
ここまで｢規範｣をやってきた人ならば、どの単語がどのように誤訳されており、本来はどういった単語なのかが分かるはずだ。

:<: b ヒント①
白頭山3大将軍(金日成･金正日･金正淑)はよく｢태양(太陽)｣や｢해(日･陽)｣という言葉で形容される。

:<: b ヒント②
①を踏まえると、｢海抜｣は少し浮いているように思えるだろう。では、｢海抜(海拔))｣は朝鮮語で何と表記するだろうか？ちなみに、漢字語である。

:<: b ヒント③
｢海｣は｢해｣、｢拔｣は｢발｣。よって｢海拔｣は｢해발｣である。
実際この単語が誤訳されているのだが、さて｢해발｣"と表記する"単語として、他にどういった単語が考えられるだろうか？そして、その単語を表記するとき、｢規範｣ではどうなっていただろうか？
